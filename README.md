# Grade 6 English – Teaching Materials (2026-2027)

Lesson plans and classroom materials for **Year 6 English (Level A2.2)** under the Türkiye Yüzyılı Maarif Modeli (TYMM) curriculum, prepared by **Ogün Aydın**.

**Free to use.** Everything here is licensed under [CC BY 4.0](LICENSE.txt): you may use, copy, print, share and adapt it for any purpose, as long as you credit *“Ogün Aydın”* and link back to this page.

## What's inside

One folder per teaching week, following the annual plan (37 weeks):

| Folder | Contents |
|---|---|
| `Grade-6_Annual-Plan_2026-2027_English` | One-page annual plan: all 37 weeks, themes, outcome codes, performance tasks, special days |
| `Grade-6_Week-03_…_Revision-Part-2` | Week 3 (revision): lesson plan, interactive board, 3 worksheets, quiz, answer key |
| `Grade-6_Week-04_…` to `Grade-6_Week-37_…` | One folder per week (Themes 1–8, the school-based planning weeks 9 and 27 and the social-activities week 37) |

Every week folder contains strictly 4 files:

| File | What it is |
|---|---|
| `…_Interactive-Lessons.html` | The interactive smartboard player for all 3 lessons (works offline in any browser; includes the “Who’s next?” dice) |
| `…_Daily-Plans.pdf` | All 3 daily lesson plans in a single 3-page document (1 page per lesson: outcomes, steps, assessment, differentiation) |
| `…_Student-Notes.pdf` | The week's vocabulary (English–Turkish), grammar explained in Turkish, and space for pupil notes (1–2 pages) |
| `…_Worksheet.pdf` | The week's worksheet: 2 pages per lesson (a duplex sheet per lesson) — 6 pages in a normal week, 4 in the project weeks |

Answer keys and diagnostic quizzes are intentionally excluded to keep classroom pacing focused and prevent online solution lookups.

Each theme ends with the official performance task: a poster, a game, a booklet, a report or a comic strip (Weeks 7, 12, 16, 20, 24, 28, 32, 36).

The language of every week follows the MoNE Year 6 English framework plan 2026-2027 (vocabulary, grammar, outcomes and performance tasks). Illustrations (from Week 4 on) were created by the author with AI tools (ComfyUI on a local computer; 24 replacement pictures with Google Gemini), checked one by one, and are released under the same licence. Atatürk photographs and flags are public-domain images from Wikimedia Commons.

## Folder and file names

Every week has its own folder, named so it sorts in order and says what it is:

```
Grade-6_Week-NN_YYYY-MM-DD--YYYY-MM-DD_English_<Topic>
```

Example: `Grade-6_Week-04_2026-10-05--2026-10-09_English_Theme-1-School-Life`

Files inside repeat the grade, week and subject, e.g. `Grade-6_Week-03_English_Lesson-Plan.pdf`, `Grade-6_Week-03_English_Worksheet-Revision-Quiz.pdf`. Each week folder contains strictly one interactive HTML file (`…_Interactive-Lessons.html`) and PDF documents for all printable materials.

## For the maintainer

The plans are generated, not edited by hand. The build system (one data file per week, plus the Python/JS modules that render the PDFs and the board) is kept locally and is not part of this repository.
